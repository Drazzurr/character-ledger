Character Ledger

Import and export

Character Ledger works on its own and never needs an account. Bring characters in from Roll20, D&D Beyond or a Ledger backup by pasting text or choosing a file, and take them out the same way.

Bring characters in

Paste the export here, or choose a .json file. Ledger recognises the format by itself. New characters land in the campaign you have selected.

How to get a character from D&D Beyond

D&D Beyond has no official export for other apps. This uses the same data its own character page loads, which is unofficial and could stop working.

The character must be set to Public. D&D Beyond defaults to "campaign only", and that gives an error here. On D&D Beyond open the character, go to its settings (Manage, then Character Privacy), choose Public, and save.

Then paste the character page link, or just its ID number, below and tap Fetch. If Fetch cannot reach it, open the link that appears. Long characters are too big to copy on some phones, so on a computer you can open that link, save the page as a .json file (Ctrl+S), and bring the file here with Choose file.

Imported: abilities, hit points, class and level, proficiencies, spells, features, inventory and coins. Armor class and attack bonuses are estimates, so check them. Characters come in as 5e (2014); change Rules on the sheet for a 2024 character. Features and feats are copied exactly as D&D Beyond lists them for the character, including any added by a campaign or homebrew source, so delete anything you do not want on the Sheet. Importing the same character again replaces the earlier copy.

How to get a character from Roll20

Roll20 has no built-in character export for outside apps. If you have a Roll20 API script or an exporter tool that outputs a character's attributes as JSON (a list of objects with name, current and max), paste that here. Basic stats, proficiencies, hit points and class come across; spells, features and gear are not in that data, so add those in Ledger.

Take characters out

Large characters can be too big to copy on a phone, so use the Save buttons to get a file instead. A full backup holds every campaign, character and your Library, and can be imported back into Ledger on any device. The Roll20 option writes basic stats using the D&D 5e Roll20 sheet's attribute names; check the character in Roll20 afterwards to confirm the fields landed where you expect.

Storage on this device

Checking...

Your characters save automatically as you type, in two places on this device. If the browser ever loses one copy, the app restores it from the other.

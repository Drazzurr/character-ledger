How to get a character from D&D Beyond

D&D Beyond has no official export for other apps. This uses the same data its own character page loads, which is unofficial and could stop working. It usually works for characters set to Public.

1. On D&D Beyond, set the character's privacy to Public. 2. Paste your character page link, or just its ID number, below. 3. Open the link that appears, select all the text on that page, copy it and paste it above.

Imported: abilities, hit points, class and level, proficiencies, spells, features, inventory and coins. Armor class and attack bonuses are estimates, so check them. Characters come in as 5e (2014); change Rules on the sheet for a 2024 character. Importing the same character again replaces the earlier copy.

How to get a character from Roll20

Roll20 has no built-in character export for outside apps. If you have a Roll20 API script or an exporter tool that outputs a character's attributes as JSON (a list of objects with name, current and max), paste that here. Basic stats, proficiencies, hit points and class come across; spells, features and gear are not in that data, so add those in Ledger.

Take characters out

A full backup holds every campaign and character and can be imported back into Ledger on any device. The Roll20 option writes basic stats using the D&D 5e Roll20 sheet's attribute names; check the character in Roll20 afterwards to confirm the fields landed where you expect.
